# סוכן שולחן עבודה – Claude שולט במחשב

סוכן שרץ **על המחשב שלך**, מקבל משימות בטקסט (גם בעברית), ומבצע אותן בעזרת העכבר והמקלדת. הוא רואה את המסך דרך צילומי מסך.

## התקנה (פעם אחת)

1. מתקינים Python 3.10 ומעלה מ-<https://www.python.org/downloads/>. ב-Windows מסמנים בהתקנה את **Add Python to PATH**.
2. מקבלים מפתח API מ-<https://console.anthropic.com/> (בתפריט **API Keys**). השימוש בתשלום, לפי כמות השימוש.
3. מגדירים את המפתח כמשתנה סביבה:
   - **Windows** (פותחים CMD ומריצים, ואחר כך פותחים חלון חדש):
     `setx ANTHROPIC_API_KEY "sk-ant-..."`
   - **Mac/Linux** (מוסיפים לקובץ `~/.zshrc` או `~/.bashrc`):
     `export ANTHROPIC_API_KEY="sk-ant-..."`
4. **ב-Mac בלבד:** פותחים **System Settings → Privacy & Security** ונותנים ל-Terminal הרשאות **Accessibility** ו-**Screen Recording**.

## הפעלה

- **Windows:** לחיצה כפולה על `run-windows.bat`
- **Mac/Linux:** `./run-mac-linux.sh`

בהפעלה הראשונה הספריות הנדרשות מותקנות אוטומטית.

## שימוש

כותבים משימה ולוחצים Enter. לדוגמה:

```
> תפתח את המחשבון ותחשב 125*8
> תפתח את התיקייה Downloads ותמיין לפי תאריך
```

המשימות נכנסות לתור ומבוצעות אחת אחרי השנייה.

| פקודה | מה היא עושה |
|---|---|
| `stop` / `עצור` | עוצר את המשימה שרצה עכשיו |
| `cancel 3` / `בטל 3` | מבטל את משימה מספר 3 (בתור או בזמן ריצה) |
| `clear` / `נקה` | עוצר את המשימה הנוכחית ומרוקן את התור |
| `list` / `רשימה` | מציג את המשימה שרצה ואת המשימות שבתור |
| `quit` / `יציאה` | יציאה |

### עצירת חירום
- **F12**: עוצר את המשימה מכל חלון (גם כשהטרמינל לא בפוקוס).
- **עכבר לפינה השמאלית העליונה של המסך**: עצירה מיידית.
- **Ctrl+C** בחלון הטרמינל: יציאה מהתוכנה.

## אפשרויות

```
python agent.py --confirm        # מבקש אישור לפני כל לחיצה או הקלדה (מומלץ בהתחלה)
python agent.py --effort high    # חשיבה מעמיקה יותר (איטי ויקר יותר)
python agent.py --max-steps 120  # מאפשר משימות ארוכות יותר
python agent.py --keep-context   # המשימות זוכרות זו את זו
```

## בטיחות – חשוב לקרוא

- הסוכן שולט **במחשב האמיתי שלך**. בהתחלה כדאי להריץ עם `--confirm` ולהשגיח עליו.
- הוא מונחה לבקש אישור לפני פעולות בלתי הפיכות: מחיקה, שליחת הודעות, רכישות. בכל זאת, אל תשאיר אותו לבד עם דברים רגישים.
- הוא לא אמור להקליד סיסמאות או פרטי תשלום. סגור חלונות רגישים לפני שאתה מפעיל אותו.
- צילומי המסך נשלחים ל-API של Anthropic כדי שהמודל יוכל לראות את המסך.

## עריכת וידאו

הסוכן יכול להפעיל תוכנות עריכה (CapCut, Premiere, DaVinci וכו') דרך המסך, אבל זה איטי. לעריכות פשוטות (חיתוך, חיבור קטעים, דחיסה, הוספת כתוביות) מהיר ואמין יותר לבקש ממנו להשתמש ב-ffmpeg, אם הוא מותקן אצלך.
