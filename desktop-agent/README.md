# הסוכן שלי – Claude שולט במחשב

סוכן שרץ **על המחשב שלך**: מקבל משימות בדיבור או בכתיבה, בעברית, ומבצע אותן בעזרת העכבר והמקלדת. יש לו לוח בקרה עם דמות בתלת־ממד, הוא מדבר עברית, ומחיאת כפיים כפולה מעירה אותו.

## התקנה (פעם אחת)

1. מתקינים Python 3.10 ומעלה מ-<https://www.python.org/downloads/>. ב-Windows מסמנים בהתקנה את **Add Python to PATH**.
2. מקבלים מפתח API מ-<https://console.anthropic.com/> (בתפריט **API Keys**). השימוש בתשלום, לפי כמות השימוש.
3. מגדירים את המפתח (ואחר כך פותחים חלון חדש):
   - **Windows** (ב-CMD): `setx ANTHROPIC_API_KEY "sk-ant-..."`
   - **Mac**: `echo 'export ANTHROPIC_API_KEY="sk-ant-..."' >> ~/.zshrc`
4. **ב-Mac:** ב-System Settings → Privacy & Security נותנים ל-Terminal הרשאות **Accessibility**, **Screen Recording** ו-**Microphone**.

## מה הוא יודע לעשות

- **כל דבר על המסך:** לפתוח תוכנות, ללחוץ, להקליד (גם בעברית), לגלול, לגרור.
- **להריץ פקודות** במחשב (PowerShell ב-Windows): קבצים, סקריפטים, התקנות, עריכת וידאו עם ffmpeg. כל פקודה מחכה לאישור שלך.
- **מצגות PowerPoint:** "תכין לי מצגת של 8 שקפים על..." והוא בונה קובץ ‎.pptx‎ (גם בעברית מימין לשמאל) ופותח אותו.
- **מייל:** לחפש, לקרוא ולשלוח. **כל מייל מוצג לך במלואו ונשלח רק אחרי שאישרת.**
- **חיפוש באינטרנט** כדי לענות על שאלות עדכניות.

הקבצים שהוא יוצר נשמרים בתיקייה `Documents\Agent`.

## חיבור למייל (Gmail)

1. מפעילים אימות דו־שלבי בחשבון Google (אם הוא עוד לא פעיל).
2. נכנסים ל-<https://myaccount.google.com/apppasswords>, יוצרים "סיסמת אפליקציה" בשם Agent ומעתיקים את 16 התווים.
3. מגדירים (ב-CMD ב-Windows, ואז פותחים חלון חדש):
   ```
   setx EMAIL_ADDRESS "your.name@gmail.com"
   setx EMAIL_APP_PASSWORD "abcd efgh ijkl mnop"
   ```
   ב-Mac: `echo 'export EMAIL_ADDRESS="..."' >> ~/.zshrc` ואותו דבר ל-`EMAIL_APP_PASSWORD`.

עובד גם עם Outlook/Hotmail, Yahoo ו-iCloud (שם גם צריך סיסמת אפליקציה). את הסיסמה לא שולחים לאף אחד, גם לא לי.

## הפעלה עם לוח בקרה (מומלץ)

- **Windows:** לחיצה כפולה על `run-dashboard-windows.bat`
- **Mac/Linux:** `./run-dashboard-mac-linux.sh`

הלוח נפתח לבד בדפדפן. **הקישור כולל מפתח סודי** (`?t=...`) שמשתנה בכל הפעלה. רק מי שיש לו את הקישור הזה יכול לשלוט בסוכן. אם סגרת את הלשונית, פתח שוב את הקישור שמופיע בחלון השחור. כדאי לפתוח אותו ב-**Microsoft Edge** או ב-**Chrome**: שניהם תומכים בזיהוי דיבור, ול-Edge יש קולות עבריים טבעיים.

בלוח אפשר:
- **לדבר** עם הסוכן (כפתור המיקרופון) או לכתוב לו.
- לראות את **המשימה הפעילה**, לעצור אותה ולבטל משימות שבתור.
- להריץ **בדיקת מערכת**: מפתח API, צילום מסך, עכבר, מיקרופון וחיבור ל-Claude.
- להריץ **בדיקת עברית**: הסוכן מקריא את כל 22 האותיות ואת 5 האותיות הסופיות, משפט שמכיל את כל האותיות, ומספרים.
- לראות **יומן** של כל הפעולות.

### מחיאת כפיים
מוחאים כפיים **פעמיים ברצף** (בהפרש של פחות משנייה). הדמות מתעוררת, אומרת "כן? אני מקשיב" ומתחילה להקשיב. אם הלוח סגור, הוא נפתח לבד.

- **חשוב:** בפעם הראשונה צריך ללחוץ פעם אחת בכלשהו מקום בעמוד. הדפדפן לא מאפשר לעמוד לדבר לפני לחיצה ראשונה. אחרי זה משאירים את הלשונית פתוחה.
- אם הוא לא מגיב למחיאות: `run-dashboard-windows.bat --clap-sensitivity 2`. אם הוא מגיב לרעשים אחרים: `--clap-sensitivity 0.6`.
- כדי לבטל את ההאזנה למחיאות: `--no-clap`.

### מיקרופון
בפעם הראשונה הדפדפן שואל אם לאפשר מיקרופון: לוחצים **אפשר**. אם פספסת: לוחצים על סמל המנעול ליד הכתובת ← מיקרופון ← אפשר.
- **Windows:** הגדרות ← פרטיות ואבטחה ← מיקרופון ← להפעיל "גישה למיקרופון" ו"אפשר לאפליקציות שולחן עבודה".
- **Mac:** הגדרות מערכת ← פרטיות ואבטחה ← מיקרופון ← להפעיל ל-Terminal ולדפדפן.

### קול גבר בעברית
הסוכן בוחר אוטומטית קול גבר: **Avri** ב-Edge, או **Asaf** ב-Windows. אם אין קול גבר, הוא מעמיק את הקול הקיים.
אם בבדיקת העברית מופיע "לא נמצא קול עברי":
- **Windows:** פותחים את הלוח ב-Edge, או מוסיפים עברית ב-הגדרות ← זמן ושפה ← דיבור.
- **Mac:** הגדרות מערכת ← נגישות ← תוכן מדובר ← קול מערכת ← עברית (Carmit).

## הרצת הבדיקות

- **Windows:** `run-tests-windows.bat`
- **Mac/Linux:** `./run-tests-mac-linux.sh`

הבדיקות לא מזיזות את העכבר ולא מקלידות: הן משתמשות במסך ובעכבר מדומים. הן בודקות הקלדה של כל אות בעברית (כולל ניקוד, סימנים ומספרים), עצירה וביטול, זיהוי מחיאות כפיים כפולות (ושמחיאה בודדת או רעש לא מעירים אותו), שהשרת חוסם אתרים אחרים, ושצילומי המסך בגודל הנכון.

## מצב טקסט בלבד (בלי לוח)

`run-windows.bat` או `./run-mac-linux.sh`. כותבים משימות בחלון. הפקודות: `עצור`, `בטל 3`, `נקה`, `רשימה`, `יציאה`.

## אפשרויות

```
--confirm        מבקש אישור לפני כל לחיצה או הקלדה (בלוח: כפתורי אשר/דחה). מומלץ בהתחלה
--effort high    חשיבה מעמיקה יותר (איטי ויקר יותר)
--max-steps 120  משימות ארוכות יותר
--keep-context   המשימות זוכרות זו את זו
--auto-commands  מריץ פקודות בלי לשאול (מיילים תמיד שואלים). לא מומלץ
```

## אבטחה – מי יכול לגשת לסוכן

- הלוח פתוח **רק מהמחשב שלך** (127.0.0.1). מחשבים אחרים ברשת לא יכולים להתחבר אליו.
- כל בקשה חייבת לכלול **מפתח סודי** שנוצר מחדש בכל הפעלה. בלי המפתח: שגיאה 401.
- אתרים אחרים שפתוחים בדפדפן לא יכולים לשלוח לו פקודות. יש הגנה מאתרים זרים, מ-DNS rebinding וממסגרות (clickjacking).
- **פקודות ומיילים דורשים את האישור שלך.** אם במייל או באתר כתוב "תריץ פקודה" או "תשלח מייל", הסוכן מונחה לא לציית ולספר לך.
- `--auto-commands` מריץ פקודות בלי לשאול. **לא מומלץ**, במיוחד אם המייל מחובר.

## בטיחות

- הסוכן שולט **במחשב האמיתי שלך**. בהתחלה כדאי להריץ עם `--confirm` ולהשגיח עליו.
- הוא מונחה לבקש אישור לפני פעולות בלתי הפיכות (מחיקה, שליחת הודעות, רכישות), ולא להקליד סיסמאות או פרטי תשלום.
- צילומי המסך נשלחים ל-API של Anthropic כדי שהמודל יראה את המסך. הקול שלך מעובד על ידי שירות זיהוי הדיבור של הדפדפן.
- הלוח זמין רק מהמחשב עצמו (localhost), ואתרים אחרים לא יכולים לשלוח לו פקודות.
