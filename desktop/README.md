# שוקי — אנליסט הבורסה למחשב

בוט שמנתח מניות ורץ אצלך על המחשב.
**בלי מפתחות API, בלי הרשמה, בלי הגדרות.**

## למה זה עובד בלי מפתחות

ספקי נתוני המניות החינמיים מגישים מידע לדפדפנים, לא לשרתי ענן. אתר שמתארח בענן
נחסם על ידם ולכן חייב מפתח בתשלום. **מהמחשב הביתי שלך אין חסימה**, אז אותם נתונים
בדיוק זמינים בחינם.

## הפעלה

### Mac

1. לחיצה כפולה על **`שוקי.command`**
2. הדפדפן ייפתח לבד

בפעם הראשונה macOS עשוי להזהיר שהקובץ הורד מהאינטרנט. אם זה קורה:
לחיצה ימנית על הקובץ → **Open** → **Open** שוב.

### Linux

```
./start.sh
```

## דרישה חד-פעמית: Node.js

macOS לא מגיע עם Node מותקן. אם הוא חסר, ההפעלה תגיד לך את זה בעברית ותפנה
להתקנה — כשתי דקות, פעם אחת בלבד:

1. [nodejs.org](https://nodejs.org)
2. הורד את הגרסה המסומנת **LTS**
3. פתח את הקובץ שהורדת ולחץ Continue עד הסוף

אחרי זה, כל הפעלה היא לחיצה כפולה אחת.

## מה הוא עושה

**סימבול אחד** — למשל `AAPL` — ניתוח מלא: ציון מ-0 עד 100, המלצה, פירוט כל
הסיגנלים הטכניים והפונדמנטליים עם המספר שמאחורי כל אחד, וסיכום בעברית.

**כמה סימבולים** — למשל `AAPL, NVDA, MSFT` — טבלת דירוג מהחזק לחלש.

מניות ישראליות: הוסף `.TA` לסימבול, למשל `TEVA.TA`.

## מה בפנים

| קובץ | תפקיד |
| --- | --- |
| `server.mjs` | השרת המקומי וה-API |
| `ui.html` | הממשק — עמוד יחיד, בלי ספריות חיצוניות |
| `שוקי.command` | ההפעלה ל-Mac |

הניתוח עצמו מגיע מ-`../lib` — אותו מנוע שמכוסה ב-118 בדיקות.
**אפס תלויות:** הכל רץ על ספריית התקן של Node, ולכן אין `npm install`.

## הבהרה

הציון מופק ממודל אוטומטי. אין לראות בניתוח ייעוץ השקעות, שיווק השקעות או תחליף
לייעוץ אישי המתחשב בנתונים ובצרכים של כל אדם.
