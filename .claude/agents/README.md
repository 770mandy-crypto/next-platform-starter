# סוכני AI מתמחים (Subagents)

צוות של סוכנים, כל אחד מומחה בתחום אחד. Claude Code בוחר את הסוכן המתאים
אוטומטית לפי הבקשה, או שאפשר לקרוא לו במפורש: "תשתמש ב-<שם-הסוכן>".

| סוכן | מה הוא עושה | דוגמת בקשה |
|------|-------------|-------------|
| `security-auditor` | מוצא חולשות ובעיות אבטחה **בקוד/באתר שלך** ומסביר איך לתקן | "תבדוק את האתר שלי לבעיות אבטחה" |
| `bug-hunter` | סורק את הקוד ומוצא באגים ובעיות נכונות | "תמצא באגים בפרויקט הזה" |
| `researcher` | חוקר נושא ממספר מקורות ומסכם עם הפניות | "תחקור מה האפשרויות ל-X" |
| `deep-analyst` | צולל לעומק בבעיה/קוד מורכב ומסביר לפרטים | "תסביר לעומק איך X עובד" |
| `code-reviewer` | סוקר שינויים/PR ונותן ביקורת ממוקדת | "תעשה code review לשינויים שלי" |

## איך זה עובד
- כל קובץ `.md` בתיקייה הזו הוא סוכן. ה-frontmatter (`name`, `description`,
  `tools`, `model`) מגדיר מתי הוא מופעל ואילו כלים יש לו; הטקסט שאחריו הוא
  הוראות המערכת שלו.
- הפעלה: כתוב בקשה טבעית ("תמצא את הבעיות באתר הזה") ו-Claude ינתב לסוכן
  המתאים, או ציין במפורש: "השתמש ב-security-auditor".
- אפשר להריץ כמה סוכנים במקביל על משימות בלתי-תלויות.

## חשוב לגבי אבטחה
`security-auditor` הוא כלי **הגנתי**: הוא בודק אתרים/קוד ש**בבעלותך** או שיש לך
הרשאה כתובה לבדוק, ומטרתו למצוא בעיות כדי לתקן אותן. הוא לא נותן הנחיות
לתקיפת אתרים של אחרים.

## להוסיף סוכן חדש
העתק אחד מהקבצים, שנה את ה-`name`, ה-`description` (מתי להפעיל אותו),
ה-`tools` וההוראות. שמור עם שם קובץ תואם ל-`name`.
